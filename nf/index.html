¿Qué es la Programación?

La programación es el proceso de crear un conjunto de instrucciones que le dicen a una computadora cómo realizar un trabajo. Se utiliza para crear aplicaciones, sitios web, videojuegos y los sistemas operativos que usamos día a día.

Lenguajes de Desarrollo Web

HTML

Es la estructura y el esqueleto de una página web.

CSS

Encargado del diseño, los colores y los estilos visuales.

JavaScript

Aporta la lógica, la interactividad y dinamismo.
